# 다윗 프로젝트 시즌 2 진행관리

카카오톡 대화 내보내기 파일을 가져와 2026년 10월 4~31일 말씀·운동 인증을 관리하는 관리자 전용 웹앱입니다.

## 사용

1. 기존 새벽이슬 출석 앱의 지정된 관리자 PIN으로 로그인합니다.
2. 카카오톡에서 `.txt` 대화 파일을 내보내 `대화 파일 가져오기`를 누릅니다. 같은 파일을 다시 가져와도 중복되지 않습니다.
3. 사진·동영상은 파일에 실제 내용이 들어 있지 않으므로 카카오톡에서 확인한 뒤 말씀·운동 버튼을 각각 누릅니다.
4. 오전 4시 전 게시물은 전날로 표시됩니다. `게시물 내역`에서 날짜를 바꿀 수 있습니다.
5. `엑셀 내보내기`로 참가자 요약, 28일 기록, 게시물 확인 내역을 받습니다.

앱은 대화 원본 파일과 첨부 미디어를 서버에 보관하지 않습니다. 게시물 종류·시각·최대 180자의 표시 내용만 저장합니다. 기존 출석 기록은 읽거나 수정하지 않습니다.

## 개발

```powershell
npm install
npm run check
npm run dev
```

별도 Supabase 테이블과 `david-tracker` Edge Function을 사용합니다. 공개 데이터 API에서는 프로젝트 테이블 접근을 차단하고, 함수가 기존 PIN 로그인 토큰과 관리자 프로필을 검증합니다. 배포 주소는 `https://changhyun-leek.github.io/david-project-tracker/`입니다.
