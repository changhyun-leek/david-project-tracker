# 다윗 프로젝트 시즌 2 진행관리

카카오톡 대화 내보내기 파일을 가져와 2026년 10월 4~31일 말씀·운동 인증을 관리하는 관리자 전용 웹앱입니다.

## 사용

1. 첫 화면 이름 칸에 기존 새벽이슬 출석 앱의 관리자 PIN(숫자)을 넣으면 관리자 화면으로 들어갑니다. 숫자가 아니면 참가자 이름으로 처리합니다.
2. 카카오톡에서 `.txt` 대화 파일을 내보내 `대화 파일 가져오기`를 누릅니다. 같은 파일을 다시 가져와도 중복되지 않습니다.
3. 사진은 말씀, 동영상은 운동으로 자동 표시됩니다(점선). 참가자가 직접 체크한 것도 `(본인)`으로 보입니다. 카카오톡에서 확인한 뒤 `이대로 확정`이나 `자동 판정 모두 확정`을 누르거나, 말씀·운동 버튼으로 고쳐서 확정합니다. 확정 전 기록은 순위와 엑셀 완료 집계에 들어가지 않습니다.
4. 오전 4시 전 게시물은 전날로 표시됩니다. `게시물 내역`에서 날짜를 바꿀 수 있습니다.
5. `엑셀 내보내기`로 참가자 요약, 28일 기록, 게시물 확인 내역을 받습니다.

앱은 대화 원본 파일과 첨부 미디어를 서버에 보관하지 않습니다. 게시물 종류·시각·최대 180자의 표시 내용만 저장합니다. 기존 출석 기록은 읽거나 수정하지 않습니다.

## 참가자 화면

같은 주소를 단톡방에 공유하면 참가자가 이름(명단 이름이나 카톡 표시명)으로 들어와 오늘·어제의 말씀·운동을 직접 체크하고, 내 28일 기록과 누적 순위(확정된 말씀 1점 + 운동 1점)를 봅니다. 새나 큐티(두란노) 바로가기 버튼이 있습니다. 이름만으로 들어오므로 본인 체크는 참고용이고, 순위에는 관리자가 확정한 기록만 반영됩니다.

## Windows 바탕화면 바로가기

`scripts/install-desktop-shortcut.ps1`을 실행하면 바탕화면에 `다윗 프로젝트 진행관리` 바로가기가 생깁니다. Chrome의 앱 창으로 열리며, 기존 Chrome 기본 프로필의 로그인 상태를 사용합니다. 전용 아이콘은 `%LOCALAPPDATA%\DavidProjectTracker\david.ico`에 저장됩니다.

## 개발

```powershell
npm install
npm run check
npm run dev
```

별도 Supabase 테이블과 `david-tracker` Edge Function을 사용합니다. 공개 데이터 API에서는 프로젝트 테이블 접근을 차단하고, 함수가 기존 PIN 로그인 토큰과 관리자 프로필을 검증합니다. 배포 주소는 `https://changhyun-leek.github.io/david-project-tracker/`입니다.
